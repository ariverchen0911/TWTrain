三、估算假設

  • POC 第一版採 HTML5、CSS3、原生 JavaScript、CesiumJS CDN 或 fallback 示意圖，不先納入正式後端、資料庫與真實設備連線。
  • 正式系統估算已預留未來 FastAPI/PostgreSQL/PostGIS/MQTT/API 邊界，但未納入台鐵正式 API 審查或內部網路上線所需之額外資安設備。
  • CCTV 原始連續影像依 MD 原則保留於現場 NVR，估算僅含平台入口與事件快照索引，不含大量影像雲端保存容量。
  • 雲端與備份以 36 個月基本平台服務預留，每月 18,000 元；實際應依正式流量、資料保存年限、備援等級與採購方案調整。
  • 職安費依工程詳細表附註採 011 工程費 3%；品管費則依表內品管人員與文件項目另估。

四、未納入與高風險變動項

  • 正式測量與高程基準：20 點、2 雨量筒、4 CCTV 的正式 GNSS 座標與高程尚未提供。
  • 現場土建與管線：若需新增基礎、保護管、穿越軌道或特殊夜間封鎖施工，成本需另估。
  • 設備廠牌與協定：Modbus、MQTT、HTTP、ONVIF 或私有協定不同會影響介接工時。
  • 告警值與通報程序：正式警戒值、解除條件、行控或值班室通報程序尚待機關核定。
  • 資安與內網部署：VPN、弱掃、滲透測試、機關 SSO、憑證與內部 API 上線流程未列入固定單價。

五、結論

本次以來源表的台鐵工程項目格式重建資訊系統估算。若以第一版 POC、地圖與儀表板、資料查詢、API 邊界、三年維護與平台服務一併納入，建議含稅預算抓約 1,246 萬元，並以 1,059 萬至 1,495 萬元 作為現勘與正式規格確認前的合理規劃帶。後續一旦取得正式座標、設備型號、通訊方案、NVR 保存策略與台鐵 API 標準，應回填單價分析表並重算。
