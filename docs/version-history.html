本次六項更新

  1. 北向區域：以北口規劃座標 121.4103°E、23.6993°N 為 3D 初始目標，朝北、俯角 50°、觀測距離 2,200 公尺。2D 初始範圍為 121.403～121.418°E、23.695～23.709°N。
  2. 直接顯示 EMAP01：改用 Cesium 1.119 的 baseLayer 建立唯一底圖；移除藍色天空、大氣霧化與水面效果。ESRI 全球影像與 OSM 可切換。
  3. 全球 DEM：接入 Esri WorldElevation3D / Terrain3D，地形採實際高程；鐵道線、設施、監測點與標籤貼地顯示。使用固定日光呈現，並非即時日照模擬。提供地形載入失敗與重試狀態。
  4. 右上資訊面板：以實際隱藏狀態關閉，保留固定關閉按鈕；更新內容不再替換按鈕。支援 Escape，且關閉後不會因模擬更新自行重開。
  5. 完整性與版次：新增此版更紀錄與可重跑測試；修正明細同步、查詢匯出範圍、門檻驗證、累積雨量、離線設備接收率及告警總數。
  6. 返回初始範圍：地圖左上定位按鈕可恢復北口初始位置與視角；2D / 3D 各有對應範圍。

區內仍可平移、縮放與旋轉。操作結束時若畫面中心超出 121.395～121.427°E、23.689～23.719°N，會回到初始範圍；縮放距離限制為 150～6,000 公尺。此為 POC 導航範圍，不是契約用地或工程界址。

資料來源與使用界線

  • 需求依據：ref/光復隧道監測資訊整合系統_細部規劃設計與POC開發規格.md。本次使用者更新需求優先於該文件舊版地形設定。
  • 台鐵 GeoJSON：既有 data/hualien-railway-layers.geojson，由來源 EPSG:3826 轉為 EPSG:4326；本次未修改原始設施資料。
  • 底圖：內政部國土測繪中心 EMAP01、Esri World Imagery、OpenStreetMap contributors。
  • 地形：Esri WorldElevation3D / Terrain3D。技術實作參考 Cesium ArcGISTiledElevationTerrainProvider 與 Viewer 官方文件。

監測點與所有量測仍為 PLAN / 模擬資料。全球 DEM 僅用於地形視覺化，不能取代現場測量或直接作為水位警戒基準。費用估算沿用原文件，本次未重新估價。
